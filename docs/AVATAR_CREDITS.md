# Avatar credits

Profile pictures are generated locally using [DiceBear](https://www.dicebear.com/integrations/javascript/). The DiceBear core library is MIT licensed; avatar artwork has separate licences.

| Style | Creator | Licence / permission |

| [Fun Emoji](https://www.dicebear.com/styles/fun-emoji/) | [Davis Uche](https://www.instagram.com/davedirect3/) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| [Pixel Art](https://www.dicebear.com/styles/pixel-art/) | [DiceBear](https://www.dicebear.com) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

The artwork is used without custom changes beyond DiceBear generation and display sizing. Credits are also available in the profile picture picker. The installed style package retains its metadata and licence notices.
